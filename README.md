# graceland

Source for [welcometograceland.com](https://welcometograceland.com) — my design portfolio.

Built solo with vanilla HTML/CSS/JS, designed in Figma first and coded with Cursor. Each case study is a self-contained page so it can be shared and viewed independently.

## Pages

- `index.html` — homepage
- `ai-agent-builder.html` — case study: Regal's AI Agent Builder, designed 0→1
- `regal-copilot.html` — case study: Regal Copilot, an agentic AI layer for Regal's platform
- `regal-platform.html` — case study: Regal platform overview
- `arcana.html` — Arcana, a tarot-reading web app with a Claude API–powered chat interface
- `visual-design.html` — visual design work
- `vibecoding-intro.html` / `vibecoding4dummies.html` — a running field journal on learning to code with AI tools (Cursor, Lovable, Claude)
- `contact.html` — contact page

Shared component patterns are documented in `PORTFOLIO-SHARED-COMPONENTS.md`.

## Stack

Static HTML/CSS/JS, no build step. Deployed via Netlify with continuous deployment from this repo.
